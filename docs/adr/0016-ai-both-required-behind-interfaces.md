# 视觉层是必需的决策模型；语义分组由多模态 LLM 提议，首发 Space Bunny

管线是**两段**，两段都要，各自的选型状态不同：

| 段 | 组件 | 做什么 | 状态 |
|---|---|---|---|
| 视觉层 | **决策模型** | 版面检测 + 区域分割。输入页位图，输出区域框 | 必需，**首发 PaddleOCR 的 PP-StructureV3，自托管** |
| 决策层 | **多模态 LLM** | 语义单元分组。输入页位图 + 区域框，输出哪些区域属于同一单元 | 必需，**首发 `stealth/space-bunny-alpha`**（OpenRouter），多后端可切换 |

**多后端 = 多个 LLM 后端可切换**（AGENTS.md 的硬约束），配置切换，接口固定。

## 为什么是两段，不是一段 VLM 打通

**因为两段的成本结构相反。** 视觉层是幂等的：同一份资源同一页，切一次就够，结果与操作者
无关，可以按内容哈希缓存（[ADR-0015](./0015-resource-identity-is-content-hash.md)），
自托管的边际成本近零。决策层是每份资料都要跑一次的语义判断，需要能随时换——
所以它走 API。合成一段 VLM 的话，两个性质相反的成本被绑死在一个组件上。

**「两段式」也是明确要求过的**，不是本篇的发明。

## Jev 被否决

Jev（TypeSafe AI 的 "System One Model"，Early Access）是**纯文本**模型：单一端点
`POST /v1/decide`，输入是非结构化文本 + 声明好的 schema，输出是**类型安全的枚举值加校准
置信度**，不生成文本。它的能力清单是分类、路由、打分、从非结构化文本抽结构化字段、
验证其他 LLM 的输出——**没有版面检测、没有 OCR、没有视觉理解，它看不见图**。

接进来就得为分组单独做一条 OCR 支路 + 一次额外往返，而收益（更准的分组）用多模态
LLM 直接看位图就能拿到。**它也没有被否决的部分**：「输出枚举值加置信度」这个形态是对的，
而且值得借鉴——低置信度的分组可以高亮出来请操作者确认。把它记下来的是它的输入形态。

## 关键：不为分组做 OCR

多模态 LLM **直接吃页位图**。这让 [ADR-0008](./0008-image-only-rasterize-first.md)
的边界变得干净：读进来的是**位图**，产出的是**裁切位图区域**，全程没有抽出任何文字，
也没有任何字被重建。ADR-0008 砍掉的两件事——为显示而读文档文字层、为提高分辨率而
重建文字——一件都没发生。

## Consequences

- **视觉层首发 PP-StructureV3，自托管。** 理由：它是 PaddleOCR 3.x 的文档结构管线，
  而 [ADR-0009](./0009-rasterize-server-side-pdf-images-only.md) 已经把服务端的 Python
  依赖定成 PyMuPDF + PaddleOCR——不再多一个运行时；它按页独立、幂等，能进缓存；
  边际成本近零。**这是工程判断，不是实测结论**：首张票要用真试卷验它在扫描件上的
  区域质量，验不过就换——接口固定在「页位图 → 区域框」这一层，换实现不改调用方。
  调研里另有 PP-DocLayoutV3 与 PaddleOCR-VL 作为候选，见 `docs/research/decision-models.md`。
- **Space Bunny Alpha 的事实**（取自 OpenRouter 公开模型接口）：`text+image+video -> text`，
  1M 上下文，**prompt 与 completion 都是 0**（免费），上线于 2026-09-23。
- **三个风险，接口可切换就是它们的解药**：
  1. **免费意味着随时可能变价或消失**。定价不是承诺。
  2. **`stealth` 是匿名第三方供应商，prompt 可能被留存**。这意味着**校内试卷的
     页位图会传给一个匿名的外部服务**——知情即可，不构成阻塞项。
  3. **刚上线两天**，输出格式与行为随时可能变。所以接口必须固定在
     「一组区域框 → 一个分组」这一层，模型侧的格式变化被适配层吸收。
- **「多后端」指多个 LLM 后端可切换**。首发只有 Space Bunny，第二个、第三个随时加——
  这条不构成待定项，接口固定就够。
- **1M 上下文对这个任务过剩。** 不要因为它大就把整份资料塞进去——输入是
  页位图 + 区域框，分组只需要局部。
- **决策层失败或超时不拖垮视觉层**：LLM 分组挂了就**不分组**，解析仍然成功。
  拆分已经成功了，让分组失败把整次解析判失败是把次要步骤当成必要步骤。
  操作者可以手工分组。
- **API key 只在服务端**，绝不下发客户端。
- 延迟与内存预算见 [ADR-0019](./0019-latency-and-memory-budget.md)。
